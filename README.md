# CrewSync (Electron)

**Crew Signals(crew.you)의 "비즈니스 신호" 피드에 올라오는 리포트를 읽어, 리포트마다 들어 있는 "5가지 자동화 수익 아이디어"를 뽑아 구글 시트에 쌓아 주는 데스크톱 앱**입니다. AI를 쓰지 않고 규칙(정규식)으로 뽑기 때문에 토큰이 들지 않습니다.

## 동작 순서

| 단계 | 하는 일 | 코드 |
| --- | --- | --- |
| 1 | 구글 시트에 연결하고, 이미 들어 있는 리포트 목록을 읽음 (없는 탭은 새로 만들고 머리글도 씀) | `src/sheets.js` |
| 2 | 숨김 창으로 피드를 열어 "Load more / 더보기"를 끝까지 눌러 모든 리포트 링크를 모음 | `src/scraper.js` |
| 3 | 시트에 없는 새 리포트만 골라 한 편씩 열고 본문을 읽음 (편마다 0.4초 쉼) | `src/main.js` |
| 4 | 본문에서 번호 1~5로 시작하는 아이디어 5개를 뽑고, 금액·% 표현을 따로 모음 | `src/parser.js` |
| 5 | 50행이 모일 때마다, 그리고 끝날 때 시트에 추가 | `src/sheets.js` |

시트 열: `발행일 | 리포트 제목 | 링크 | 번호 | 아이디어 제목 | 내용(실행 방법) | 수익화 모델·수치`

5개를 못 뽑은 리포트는 번호 `0`, 제목 "(자동 추출 실패 - 원문)", 본문 앞 3000자를 넣은 한 줄로 남기고 로그에 "확인 필요"로 알려 줍니다.

## 실행

```bash
npm install
npm start
```

## exe/dmg 만들기

```bash
npm run dist     # electron-builder --win --mac
```

주의: `--win --mac`을 함께 주므로, 운영체제에 따라 한쪽 빌드가 실패할 수 있습니다 (맥용은 보통 맥에서만 빌드됨). 한쪽만 필요하면 `package.json`의 `dist` 명령에서 다른 쪽 옵션을 지우세요.

## 구글 시트 연결 (1회)

1. 구글 클라우드 콘솔 → Google Sheets API 사용 설정 → 서비스 계정 생성 → 키(JSON) 발급
2. 대상 시트를 그 계정의 `client_email`에 **편집자**로 공유
3. 앱에서 시트 주소 입력 + JSON 선택
4. 처음에는 **시험 실행**을 체크하고 "최대 편수"를 3 정도로 두어 로그의 첫 행 미리보기를 확인한 뒤, 체크를 풀고 동기화

다시 실행하면 시트에 링크가 없는 새 리포트만 추가됩니다. (추출에 실패해 "원문"으로 들어간 리포트도 링크가 시트에 있으므로 다시 처리되지 않습니다. 다시 받으려면 그 행을 지우세요.)

## 화면 입력값

| 항목 | 설명 |
| --- | --- |
| 구글 시트 주소 | 주소 전체 또는 시트 ID |
| 서비스 계정 키(JSON) | 파일 선택 (경로만 저장하고, 키 내용은 복사·저장하지 않음) |
| 탭 이름 | 기본 `아이디어` |
| 최대 편수 | 0이면 전부 |
| 시험 실행 | 체크하면 시트에 쓰지 않고 첫 행만 로그에 표시 |

입력값은 앱 데이터 폴더의 `settings.json`에 저장됩니다. `.gitignore`에 `key*.json`, `service-account*.json`이 들어 있어 키 파일이 실수로 올라가는 것을 막아 줍니다.

## 폴더 구조

```
crew-sync-app/
├── package.json        # Electron 33, googleapis, electron-builder 설정
└── src/
    ├── main.js         # 앱 본체: 화면 창, 동기화 흐름, 설정 저장
    ├── scraper.js      # 숨김 창으로 피드·리포트 읽기
    ├── parser.js       # 본문 → 아이디어 5개 + 금액 표현
    ├── sheets.js       # 구글 시트 연결·추가
    ├── preload.js      # 화면과 본체를 잇는 통로
    ├── renderer.js     # 화면 동작
    └── index.html      # 화면
```

## 검증 상태

| 항목 | 결과 |
| --- | --- |
| JS 6개 파일 문법 | 통과 |
| `parser.js` (번호 형식 `1.` `**2.**` `3:` `4)` 혼합 샘플) | 5개 정상 추출, 5개 미만이면 빈 결과 |
| `sheets.js` (googleapis를 가짜로 대체) | 시트 ID 추출, 탭 자동 생성, 기존 링크에서 처리 완료 ID 추출, 행 추가 모두 정상 |
| Electron 창 실행, crew.you 실제 읽기, 실제 구글 시트 쓰기 | **미확인** (화면 환경·계정 없음) |
